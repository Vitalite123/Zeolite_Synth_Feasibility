# Reproduction command list

All commands are run from the repository root. The scripts resolve every path
relative to their own location, so no environment variables are needed.

## 0. Environment

```
python -m pip install -r requirements.txt
```

## 1. Supplementary analyses (S1–S4)

```
python wp2_p22_supp_v0.py
```

- Runtime: about 1 minute on a desktop CPU.
- Hard check: the script first re-derives the headline `xtal` test AUROC under the
  frozen protocol (36 boosting rounds) and compares it with the registered anchor
  `0.6307095094096244` (tolerance `1e-3`). If the check fails the script aborts
  before writing anything.
- Outputs (overwritten atomically after the check passes):
  - `Documentation/P2-2/data/wp2_p22_supp_v0_metrics.parquet` — per-setting metrics
    file (LOSO folds, learning-curve draws, noise estimators, saturation fit).
  - `Documentation/P2-2/data/wp2_p22_supp_v0_report.txt` — human-readable readings.
  - `Documentation/P2-2/data/wp2_p22_supp_v0_manifest.json` — code, data and anchor
    hashes of the run.
- Verification: the `anchor.measured` field of the new manifest must equal
  `anchor.expected` exactly, and the metrics file must reproduce every number in the
  supplementary tables of the manuscript.

## 2. Figures 3–5

```
python p22_figs_v0.py
```

- Reads `Documentation/P2-2/data/wp2_p22_supp_v0_metrics.parquet` and rewrites the
  300-dpi figures into `Documentation/P2-2/assets/`, updating
  `p22_figs_manifest.json`.
- The script contains a layout audit (text-overlap and containment checks) and
  reports each figure's audit status on stdout.

## 3. Frozen-bundle readings quoted in the manuscript

The deployment calibration record ships as `Data/m10_calib_v1_report.txt` with its
hash in `Data/m10_calib_v1_manifest.json`; the model-bundle hash is recorded in
`Data/feasibility_scorer_v1_2_manifest.json`. These files are released as-is and are
not regenerated by the commands above.
